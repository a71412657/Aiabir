# Abir AI Android starter

A simple Bengali voice assistant starter app. It can listen for spoken commands and open supported apps or searches. Microphone permission is requested when needed.

## Build

GitHub Actions builds a debug APK automatically after the project files are committed to the `main` branch. Open the Actions tab, choose the successful `Build AbirAI APK` run, then download the `AbirAI-debug-apk` artifact.

This starter is not a full ChatGPT-style AI backend; it handles the commands implemented in `MainActivity.java`.
